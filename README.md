# E-Commerce Website Optimization for Efficient Customer Use
Develop an e-commerce web application using recent technologies such as NextjS, ReactJS, ASP.NET, NodeJs, Strapi, or any recent technologies of your choice. (Flutter + Dart)

Abstract: Our project intends to develop a modern E-Commerce website designed with simplicity in mind to enhance user experience and streamline the shopping experience. Built using Flutter and Dart which includes cross-platform functionality, our application integrates with Firebase Database to securely manage customer, product, and administrator data. Core functions of this project are product browsing, account management, and order processing. Using the admins interface allows creating, editing, and deleting products and customer orders. The application currently has over 12 interactive pages with more to come, featuring a simple and refined design inspired by the Google Fi store. By combining simple functionality with a tight user-friendly design, our platform can demonstrate how an efficient and accessible online shopping experience can improve customer satisfaction and increase consumer engagement, while providing administrators with the industrial management tools they require.
